Stem Flow

朋友测试指南 · 测试版 2026-10-12
游戏界面为英文，本指南使用中文说明。

本包为 Drag Fix 拖动修复版：修复识别器短暂漏帧时清除拖动状态、导致 Reverb 数值停止响应的问题。短暂恢复时从当前位置继续，松手、长时间丢失追踪或换手后会结束旧拖动。保留上一版的渲染优化。本次请重点复测 Reverb 持续调节，以及完成练习后是否仍可继续调整。若 Next 不响应，也请尝试鼠标点击 Next，并分别记录结果。

打开游戏 Stem_Flow_Intro.html

1. 开始测试

  1. 先完整解压压缩包，再打开其中的 Stem_Flow_Intro.html。不要直接在压缩包预览窗口里运行。
  2. 使用电脑浏览器打开，保持联网。音乐已内嵌，但手势识别模型需要在线加载。
  3. 第一次玩选择 Intro（教学）；熟悉后选择 Play song（直接混音）。
  4. 点击 Enable Camera，允许摄像头权限。等待 Camera 和 Hand model 就绪。
  5. 点击 Start，将手放进镜头，保持可见，等待倒计时完成。

测试时尽量让整只手清晰入镜，避免背光。先用单手测试，再尝试双手。需要录制时，在开始前勾选 Record camera + remix audio after start；录制包含摄像头画面和混音音频。

2. 手势操作

操作手势
调节音量在目标音轨区域捏合拇指和食指，上下移动；松开后保留当前音量。
进入 FX在目标音轨区域竖起拇指，其他手指收拢，保持稳定。
调节效果在 Reverb、Delay 或 Filter 区域捏合，上下移动。
退出 FX在右下角 Quit 区域竖起拇指，保持稳定。
再次使用拇指指令先松开手势，再重新竖拇指。保持同一个拇指姿势不会连续切换。
教学下一步完成当前练习后，在 Next 上先松开，再捏合保持。Next 与 Quit 使用不同手势。

操作时尽量位于象限内部。正在捏合调节时，控制目标会保持锁定；当前只允许一只手拖动数值。

位置主界面FX 界面
左上Vocal / VocalsReverb
左下BassDelay
右上DrumsFilter
右下OtherQuit

Space：暂停／继续。M：正式混音时清除全部效果。教学中可暂停后使用跳过当前步骤或全部教学的按钮。Help 内的 Quit 按钮用于关闭帮助窗口。

3. 建议测试顺序

  1. 完成 Intro：依次尝试音量、进入 FX、三种效果、退出 FX，再开始四轨混音。
  2. 检查实时反馈：连续上下调节每个音轨，观察百分比、动画和声音是否跟随。三种效果分别重复，注意中央显示是否对应正在调节的效果。
  3. 检查误进入：正常捏合、松开、移动到其他象限，观察是否意外进入 FX。
  4. 检查误退出：调整三种效果，手经过右下区域但不竖拇指，确认没有意外回到主界面。
  5. 检查有意切换：在音轨内竖拇指进入 FX，松开，再在 Quit 内竖拇指退出。重复几次，记录漏识别或误触。
  6. 检查追踪恢复：将手短暂移出镜头后重新进入，再尝试双手，观察是否出现数值突跳或界面意外切换。

防误触逻辑会要求拇指姿势稳定后再切换；音量和效果拖动不需要等待这个切换确认过程。

4. 遇到问题

  • 摄像头打不开：检查浏览器和系统摄像头权限，关闭其他占用摄像头的程序，再刷新页面。
  • 模型一直加载：确认网络可以访问 jsDelivr；首次加载需要下载识别资源。
  • 本地文件无法使用摄像头：有 Python 3 的电脑可在解压目录运行 python3 -m http.server 8000（Windows 可尝试 py -m http.server 8000），再访问 http://localhost:8000/Stem_Flow_Intro.html。测试结束按 Ctrl+C 停止服务。
  • 明显卡顿：先关闭录制和其他占用资源的应用，再测试同样的动作，记录是否改善。
  • 录制格式：取决于浏览器支持，可能输出 MP4 或 WebM。

6. 源代码与验证

以下文件放在同一目录。无需 Node.js 即可测试游戏；修改和构建源码时需要 Node.js。

文件用途
Stem_Flow_Intro.html可运行游戏，也包含完整界面、音频与渲染源码以及内嵌资源。
stem-intro-controls.js手势稳定、防误触和教学流程的可编辑源代码。
build-stem-intro.cjs将手势源代码重新嵌入 HTML，并检查脚本语法。
test-*.cjs不依赖摄像头的模拟回归测试。

修改手势或教学时编辑 JS；修改界面、音频或渲染时编辑 HTML。之后在本目录执行：

node build-stem-intro.cjs
node test-stem-intro.cjs
node test-gesture-safety.cjs
node test-feedback-unit.cjs

本版已通过脚本语法检查及上述三组模拟测试。额外的 test-reverb-render.cjs 验证雾面绘制与零强度 Filter 的跳过逻辑；需先安装 @napi-rs/canvas，再运行 node test-reverb-render.cjs。真实摄像头下的识别准确度、设备帧率和浏览器兼容性仍需要本次朋友测试确认。
